# Original data access

The ZuCo 2.0 BIDS dataset is available from [NEMAR nm000279](https://www.nemar.org/dataset/nm000279), release v1.0.0. Notebooks use the public NEMAR file gateway to read only selected NR/TSR runs. Original .eeg, BrainVision headers/markers and EyeLink physiology remain in the temporary Colab directory `/content/zuco2_source_cache`, not Git.

The source metadata report a CC BY 4.0 licence. Credit the original authors and comply with the source terms when redistributing any derived content. This folder contains no original subject data.
