# Original data access

The ZuCo 2.0 BIDS dataset is available from [NEMAR nm000279](https://www.nemar.org/dataset/nm000279), release v1.0.0. The source adapter obtains the selected NR/TSR runs from the NEMAR file gateway. Original BrainVision and EyeLink files are required for source-to-feature reproduction.

The source metadata report a CC BY 4.0 licence. Credit the original authors and comply with the source terms when redistributing any derived content. This folder contains no original subject data.
