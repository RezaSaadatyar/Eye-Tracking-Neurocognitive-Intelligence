# Generated scientific outputs

This directory is initially empty of empirical results. Each notebook writes
its owned named outputs with a prefix from `01_*` to `06_*`. Run the notebooks
in order, review the generated files and commit only derived artefacts that
are within the repository's file-size and data-use requirements. Original
ZuCo 2.0 EEG/EyeLink recordings are never stored in this directory.

No training, evaluation or dataset download has been run in this repository
at the time these notebooks were authored.
