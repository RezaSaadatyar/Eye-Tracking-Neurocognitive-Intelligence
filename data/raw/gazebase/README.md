# GazeBase recordings

This directory contains the selected 40 original Round 1 / Session 1 recordings used in Eye-Tracking Foundations. The dataset is available from [Figshare](https://doi.org/10.6084/m9.figshare.12912257) under CC BY 4.0. Retain the original filenames and nested source structure when acquiring further recordings for a separately specified analysis. See the [dataset guide](../../README.md) for attribution and acquisition details.
